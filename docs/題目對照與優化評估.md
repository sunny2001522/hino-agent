# HINO × GenAI 題目對照與優化評估

檢視日期：2026-09-14。依據：使用者提供的題目、當前工作區程式與已編譯資料；未重新取得原始 Excel 做逐列稽核。已 fetch origin，HEAD 與 origin/main 均為 fd62d8f，無遠端落後。保留原有未提交修改。

## 判斷

原方案能展示車聯網介面，但不足以證明達成「智慧夥伴」：主畫面把安全競賽、合成人員獎勵與人資審查放在核心位置，省油協作被稀釋；AI 對話入口停用真正模型，改善多停在提醒與展示；缺少介入紀錄及量測設計。功能數量不能替代這三條核心證據。

本次把主入口改為「訊號 → 證據 → 分工 → 覆核 → 回報 → 待量測」，能作為有完整操作路徑的參賽原型。仍不能宣稱已節省燃油、已預測事故，或已具備正式車隊服務能力。

建議提案聚焦：**以調度營運經理為主要使用者，駕駛在出車前與停妥後協作回報；先解決可避免等待與歷史超速訊號的覆核。** 貨主、排名與人事不作主要展示故事。

## 資料上的重大限制

1. **487,510 筆、20 台車、2025-01 至 11 月**，不等於完整連續 11 個月。2、4、6、10 月零筆；8 月只有 24 筆／1 台車。原 aggregate.safety 在缺測月份出現 100，不能拿來展示安全改善。新工作台展示各月紀錄數，不使用該分數作結論；舊報表與獨立競賽頁仍需另行清理此口徑。
2. 怠速率是怠速紀錄／（行駛＋怠速紀錄）；超速率是超速紀錄／行駛紀錄。紀錄筆數不是事件次數，比例不是持續時間，更不是耗油占比。
3. 區域依最後 GPS 緯度分組，是展示分類，不是真實部門；沒有可信的駕駛身分綁定，就不能從車號排名推導員工績效。
4. weekly 的 facts 出現疲勞、安全帶、急加減速等事件文字，與既有 README「沒有欄位」的說明互相衝突。本次未重新驗證原始 Excel；新工作台不用這些未核對資料形成結論，不能把「不存在」或「已確認存在」任一說法寫成事實。
5. 油耗來自既有 CAN 計數差分。現有編譯程序尚需原始層稽核重設、異常跳值與跨缺測區間。500 km 只是 Demo 的短樣本門檻，不代表統計顯著或完整。
6. 安全 10%、怠速 15% 是本次規則設定，只有候選排序用途；未宣稱官方門檻、事故機率或因果關係。

## 可重算的展示數字

2025-11，同月且里程至少 500 km、油量大於零的 15 台車：總用油 12,324 L，總里程 42,613.1 km。其餘 5 台排除。

加權基線 = 12,324 ÷ 42,613.1 × 100 = **28.92 L/100km**。此值是篩選後車群的彙總，不能當作所有車型的正常標準。

若假設相同里程與條件下改善 3%，油價假設 NT$30/L：節省 369.72 L，約 NT$11,092；目標 28.05 L/100km。這是對該基線月份的**假設情境**，不是預測、實現節省或 ROI。未扣成本，不外推至全台四千輛車。

## 六週試點與成功條件

- 第 1–2 週：建立基線與資料品質規則，配對車型／路線／載重；在可行條件下分派介入與對照組。樣本數需依實際變異估算，不能預先承諾 20 台一定足夠。
- 第 3–4 週：每次只改一項等待流程或出車前提醒，保留原因、採納率、回報及誤報；監看必要作業是否受影響。
- 第 5–6 週：比較介入與對照組的前後變化，報告樣本量、缺測、信賴區間及混雜因素。前後工具只產生未驗證觀測，不能代替此評估。

提案目標（尚未驗證）：相對對照組 L/100km 改善 ≥3%；去重超速事件／1,000 km 下降 ≥10%；每案人工判讀時間降低 ≥30%；回報完成率 ≥80%。事故下降不是目前資料能支持的主要 KPI。

## 三分鐘展示順序

1. 車隊管理登入（Demo 0900-000-001），指出歷史資料範圍與尚未驗證效益。
2. 選一張怠速卡，展示分母、待確認原因與三方分工；可請 AI 以同一證據解讀。未配置模型時明示規則摘要。
3. 建立案件、填承接角色／日期／原因，記錄覆核；以 ABC-5310 可切換車輛使用者（Demo 0900-110-101）接續回報。
4. 案件停在待量測，切換效益頁調整假設，再展示前後觀測及六週試點。
5. 說明安全採出車前介入設計；預測模型、推播與真實效益留待試點驗證。

## 2026-09-14 發布補充（取代前述對應待辦）

本次已重新讀取原始 Excel 並完成兩次串流編譯，487,510 筆／20 台車與既有車輛彙總完全一致。確認來源具有 event[0..2].type、起訖時間及 duration 等欄位，因此不再說來源「完全沒有事件欄位」；事件語意與真實狀態仍需分開。

伺服器現在自行產生可信證據包，忽略瀏覽器提交的任意數值與證據文字；區域只能選已存在的示範區域。這是 Demo 資料防偽，不代表已建立真實身份驗證。新增測試涵蓋前端偽造資料與跨區證據排除。

P0 剩餘研究工作是原始計數器重設／異常值稽核、事件語意對照與模型回答品質評估。真實事故預測與節能因果效益仍須試點，不能因介面、部署或 API 測試通過就宣稱達成。
