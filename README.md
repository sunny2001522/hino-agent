## 五角色系統
- **車隊管理（RWD 會議台）**：老闆決策、人力配置／招募、薪酬覆核、安全聯賽、AI 授權與原始 iTRAQ 功能對照。
- **總負責人（RWD 管理台）**：僅管理自己區域的 KPI、駕駛與改善跟進，也可看團隊安全排行。
- **車隊駕駛（App）**：我的安全分、任務、語音／推播提醒、私密個人排名與可前進的改善計畫。
- **個人用戶（App）**：只看自己的車與行程。
- **貨主（App）**：只看必要貨況、車輛編號、ETA 與主動推播；不顯示地圖、司機個資或取消訂單功能。

## iTRAQ WEB 與 RWD

- 車隊管理與總負責人直接使用原 iTRAQ 最上方主選單：即時監控、歷史車輛、任務派遣、保修系統、數據中心、車隊管理與系統設定；各選單以原生 HTML／CSS 重刻對應畫面，不使用手冊或簡報截圖當作頁面內容。
- 全站遙測數據由 `output data_Hotai_20260511.xlsx` 編譯為 `excel-derived-data.js`：車號、時間、車輛狀態、GPS、車速／限速、怠速、高引擎負載、油耗、里程、DTC 與 journeyCode 都可追溯到原始欄位。更新來源活頁簿後，執行 `python3 scripts/build_excel_demo_data_stream.py` 重新產生前端資料。
- 原始 Excel 沒有駕駛姓名、手機、工時、出勤、薪酬、職級、訂單、ETA、準時率、急煞、疲勞與安全帶欄位；系統會明確標示資料不足，不會產生虛構人員、貨件或人事決策。
- 監控地圖、即時影像、軌跡回放、影像調閱、任務、保修、事件、月報、車輛、駕駛、管理行程、駕駛成績、圍籬與通知中心皆可逐頁快速跳轉。
- 所有角色在手機、平板與桌機寬度皆採同一套自適應版型；桌機會展開成寬版工作台，手機維持易操作的 App 介面。

## 安全聯賽與人資原則

- 團隊排名可公開比較；駕駛只能看到自己的名次，不能看到其他同仁姓名或名次。
- 獎勵以安全改善與達標為主，禁止用多接單、縮短休息或違規趕工換分數。
- 安全分不會自動扣薪、解雇或觸發裁員；低分先進入 30 天改善、申訴與人資／主管覆核。
- 車隊管理端僅以 journeyCode 與車號數提供車輛量能覆核；招募、薪酬與裁員會要求先串接人資與訂單資料，且所有人事決定均需人工核准。

> 即時影像使用明確標示的模擬 DVR 畫面；其他遙測資料以 Excel 原始欄位編譯而成。
